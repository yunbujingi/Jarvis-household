## 物品语音验收

用明确的“测试”名称，避免与真实库存混淆。日期选择当前日期之后七天，并写成完整年月日。

1. “在家庭账本入库两盒测试牛奶，放在冰箱冷藏上层，到期日是〔完整年月日〕。”
2. “测试牛奶放在哪里，还剩多少？”——应为冷藏上层、两盒。
3. “测试牛奶什么时候到期？”——应匹配给定日期，不编造保质期。
4. “未来七天有哪些物品到期？”——若给定日期在该范围内，应包含它；不把分页当全部。
5. “撤销刚才的测试入库”，再问其位置——应无这笔测试库存。
6. 另记一件不含到期日的测试电池，问到期日——应答未记录，随后撤销。

记录各步结果与从说完到开始回复的时间；失败时记下原话、预期与实际回答。必要时核对审计和工具参数，不能直接重复入库。
