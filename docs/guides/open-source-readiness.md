# 开源准备清单

**当前状态：私人仓库，准备公开所需材料；本次不改变可见性。**

## 已整理

- 可读源码、测试、README、工具契约、数据模型及通用部署示例。
- 拓扑图与请求流程图的SVG/PNG及生成脚本。
- CI、贡献说明、Issue/PR模板、变更记录与安全边界。
- 发布内容白名单与本地检查；真实数据库、密钥、接入点、控制台截图、迁移报告、旧离线包均不进入Git。
- 提交身份使用GitHub noreply邮箱，避免把私人邮箱写入新历史。

## 公开前仍需完成

- [ ] 维护者选择许可证，加入LICENSE；目前未授权公开开源分发。
- [ ] 检查所有直接/间接依赖及外部素材的许可和来源，按发布方式保留必要NOTICE。
- [ ] 完成物品真人语音验收，更新结果。
- [ ] 在目标NAS上验证通用源码部署模板；CI容器通过不等于每种NAS兼容。
- [ ] 启用并验证私密漏洞报告渠道，确定维护/支持策略。
- [ ] 再审查全部Git历史、图片、发布附件及依赖来源，不只检查工作区。
- [ ] 确认公开范围与版本，再由维护者决定改为Public及创建Release。

## 同步规则

本机`.gitignore`采用docs/deploy白名单。仓库检查拒绝常见凭据、数据库和私有部署资料；它是辅助检查，不保证发现所有秘密。每次同步仍需审查暂存差异。

代码提交不等于部署。本仓库CI不连接NAS，不持有模型或设备密钥，不发布镜像到公共仓库。生产更新仍需备份、隔离验证、保持卷身份和实际验收。

## 第三方关系

JWS使用Python库，包括MCP SDK、FastAPI、Uvicorn、cryptography、websockets及其依赖。完整已验证环境快照为requirements.lock；上线和分发前按实际解析/打包版本检查许可。

小智固件、官方MCP示例与Home Assistant仅作为外部连接和协议参考，不将其完整代码、标志或控制台截图纳入本仓库。本项目没有代表这些项目的官方授权。
