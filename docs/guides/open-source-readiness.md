# 开源预览准备清单

当前交付：0.3.0，面向小智的家庭共享账本、物品管理和MCP工具桥。私人仓库，仅供获授权用户试用；尚不是公开开源发布。

已实现：

- 入库、筛选、明确记录定位、名称/位置/日期/绝对余量纠错、消耗与撤销。
- 保留三个工具名、数据库版本1和旧请求摘要；共享账本，无成员识别。
- 无凭据安装验收、真实stdio、隔离恢复、旧密文兼容和故障测试。
- 版本约束、依赖一致性与漏洞检查、静态检查、安装包与容器CI。
- README、部署、运维、语音验收、拓扑与请求图，以及可追溯产物流程。

仍需维护者决定/验收：

- 项目许可证；第一方授权主体、全部第三方再分发义务及字体条款复核。见[许可清单](licenses.md)。
- 真实小智语音与目标NAS的0.3.0验收；ARM64容器另测。
- 公开前启用并实测私密漏洞报告渠道，审查完整Git历史与图片。
- 公开仓库、公共包、镜像、Release均需另行决定。本轮不进行。

没有个人账隔离、声纹识别、拍照识别、主动通知或跨设备编排。当前工具桥不会替代现有HA或猫咪服务。

敏感信息检查由路径白名单、常见凭据模式及人工差异审查组成，不能保证识别所有秘密。仅合成测试密文夹具可入库；真实数据库、密钥、接入点、日志和家庭数据必须留在仓库外。
