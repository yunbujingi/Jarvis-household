# 开源预览范围与发布检查

当前范围：面向小智的家庭共享账本、物品管理和 MCP 工具桥。维护者已选择 [MIT](../../LICENSE)；公共包、容器镜像和正式 Release 尚未发布。

## 已验证

- 入库、筛选、明确记录定位、名称/位置/日期/绝对余量纠错、消耗与撤销。
- 三个工具名、数据库版本 1 和旧请求摘要兼容；共享账本，无成员识别。
- 无凭据安装验收、真实 stdio、隔离恢复、旧密文兼容和故障测试。
- 依赖一致性与漏洞检查、静态检查、实际安装包与容器 CI。
- 0.3.0 Linux x86_64 NAS 部署及真实语音入库/纠错/撤销，见[脱敏验收](nas-voice-acceptance.md)。
- 公开材料限定为源码、合成测试、通用部署、文档及原创图示；私人部署截图、原始 PRD、账本/密钥/备份和连接信息不纳入 Git。
