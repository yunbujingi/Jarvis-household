# 0.3.0 NAS 与真实语音验收（脱敏摘要）

验收日期：2026-11-16；被测代码：[3310800](https://github.com/yunbujingi/Jarvis-household/commit/3310800d2d11b1d81da781a193fec3948c1071ae)。这是一次真实部署的证据摘要，不代表所有 NAS 或所有语音输入都已通过。

## 环境与升级范围

Linux x86_64 NAS、Python 3.12、非 root Docker 容器；由 0.2.1 升级到 0.3.0，复用原持久卷和官方小智 MCP 接入点，无公网应用端口。只重建账本容器，保留原有模型、音色、家居和宠物工具桥，未执行设备动作。

升级前保存一致性数据库、配套密钥、接入配置、原 Compose 和旧镜像归档；新镜像先在无网络、无正式凭据的隔离容器验证。备份在独立目录恢复后，记录与审计一致；切换后逐条核对既有记录、审计和接入配置未变化。数据库仍为版本 1。

## 发现的问题与处理

一次包含改名、位置、数量和日期的长句，位置部分被 ASR（语音识别）转写为含糊文本。模型调用省略了 location，后端保留原位置，语音也明确回答了原位置。用户最初以为整句均成功，后台核对发现差异。

随后使用独立指令“把验收物品的存放位置改为验收抽屉”，语音及落库均通过。没有替换模型、音色或凭空补写位置。实际使用中应听取写入结果；一次复杂复合指令可能需要拆成短句。后端不能判断上游未传来的语义。

## 时延与未验收项

- 用户反馈这几轮在说完后 **5 秒以内开始回答**，属于人工体感记录，不是自动测量。
- 官方控制台一组查询与纠错工具耗时分别为 **260 ms、89 ms**，样本量仅 2；不代表完整 ASR/模型/TTS 延迟，也不能据此计算有代表性的 P50/P95。
- 同名多批次消歧、日期范围筛选、扣减的自动化测试已覆盖；本次真人脚本没有覆盖全部这些组合。
- 旧镜像已导出并确认文件存在，未实际切回旧镜像；没有 ARM64 或异机灾难恢复验收。
