# 产品路线与PRD差异

目标是把小智、Home Assistant、猫咪服务和家庭账本组合为一个语音入口。当前可交付范围是账本模块与工具桥，不是完整“全能家庭Agent”。

## 当前已经具备

- 物品、位置、余量、用户到期日；费用、月度统计。
- 加密记录、原子写入、幂等、版本冲突、补偿撤销。
- 独立NAS桥接、三个MCP工具、原工具共存。
- 本机文字预览、一致性备份、校验清单与独立恢复。
- 可审计的名称/位置/到期日/绝对数量纠错，脱敏耗时和故障恢复。

## 下一步

1. 0.3.0物品入库、纠错、撤销真人语音已验收；同名批次等扩展语音组合继续验收。
2. 0.4.0a1已实现草稿明确补全/取消与撤销，隔离验证；真人语音待验收。别名与内容重复提示另行推进。
3. 自动备份运维与目标NAS/异机恢复演练。
4. 成员与数据权限，明确身份后再提供远程网页和同步。
5. 提醒预算、勿扰、周期账目、耗材提醒；校准食品规则后再讨论推荐。
6. 跨模块任务结果汇总、拍照/小票、预算与趋势。

## 对原概念PRD的约束

- 不使用未经校准的食品储存乘数、气味规则或“今天必吃”作为安全判断；当前日期仅由用户明确提供。
- “所有操作可撤销”仅适用于账本补偿，设备物理动作不能撤回。
- 沉默不是新的授权，模糊数据不自动补造；版本冲突优先于后写覆盖。
- 没有可靠说话人认证时，不宣称个人账隔离。
- 出粮不等于某只宠物吃了，设备份量不等于克数；外部设备结果只接受真实可用字段。
- 保留已验收的外部工具桥，不通过重建HA/宠物接入来扩大本项目范围。
- 当前没有主动通知、自动重试草稿或设备控制工具。

完整原PRD及用户特定决策留在本地；此页是可分享的范围摘要，不含私人家庭配置。
